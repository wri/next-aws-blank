# Contributing

Thanks for your interest in contributing.

## Getting Started

1. Fork the repository.
2. Create a branch for your change.
3. Install dependencies and run the project locally.
4. Make your changes with clear, focused commits.
5. Add or update tests where relevant.
6. Open a pull request with a clear description of what changed and why.

## Development Checklist

- Follow existing code style and project conventions
- Keep pull requests focused and reasonably small
- Include tests for bug fixes or new behavior when possible
- Update docs (such as README) if behavior or setup changes
- Ensure linting and tests pass before requesting review

## Pull Request Guidance

Include the following in your PR description:

- Summary of the change
- Motivation and context
- Testing performed
- Any follow-up work or known limitations

## Reporting Bugs

When opening an issue, include:

- A clear summary of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details (OS, browser, Node version, etc.)
