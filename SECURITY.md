# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities using GitHub's private vulnerability reporting:

1. Go to the repository's Security tab.
2. Select Advisories.
3. Click Report a vulnerability.
4. Submit the report with details and reproduction steps.

When reporting, please include:

- A description of the vulnerability
- Steps to reproduce (proof of concept if possible)
- Potential impact
- Suggested remediation (if known)

## Safe Harbor

We support and encourage good-faith security research.

If you make a good-faith effort to follow this policy when testing and
reporting vulnerabilities, we will not pursue legal action against you for your
research.

For research to be considered in good faith, please:

- Avoid privacy violations, data destruction, and service disruption
- Access only the minimum data needed to demonstrate the issue
- Do not exfiltrate, modify, or delete data belonging to others
- Stop testing and notify us immediately if you encounter sensitive data
- Keep vulnerability details confidential until we have addressed the issue
